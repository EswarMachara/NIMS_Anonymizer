One patient, or a whole folder of them

Point at a single patient's folder, or at a folder containing many patient subfolders — each is anonymized independently, with its own Anonymized ID. Any of these layouts work; files are classified by content, not by folder name.

Study auto-detected

DICOM images present → eGFR pipeline. PDF-only → KFRE pipeline. Override below if needed.

Follow-up aware

The same patient (matched by CR No / Lab No.) always gets the same Anonymized ID across visits.
